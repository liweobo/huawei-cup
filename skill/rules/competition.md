# Competition Rules

1. 优先回答全部子问题并形成最小闭环，再增加复杂模型或写作装饰。
2. Early 聚焦选题、拆题、审计和 Baseline；Middle 完成主模型与验证；Late 才做高价值改进、稳健性和论文整合；Final 停止低收益调参。
3. P0/P1、一致性、摘要关键结果和可提交性高于图表美化。
4. 当届比赛时间、AI、互联网、外部代码/数据、模板和提交要求必须从官方来源核验。
5. 未确认规则为 `UNVERIFIED`，不得自行解释为允许；旧规则标 `OUTDATED`。
6. Competition State 要持续维护当前任务、主要风险和下一最高价值动作。
