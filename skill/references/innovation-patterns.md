# Innovation Patterns

现成算法名称不构成创新：`XGBoost ≠ 创新`、`LSTM ≠ 创新`、`TOPSIS ≠ 创新`、`遗传算法 ≠ 创新`。

优先从问题重新定义、变量/指标构造、约束设计、机理解释、模型组合、误差修正、场景设计、鲁棒性分析和验证方式产生创新。

每个创新点必须回答：

1. 原方法或题目表达存在什么问题？
2. 修改了什么结构、变量、约束或验证方式？
3. 为什么修改合理且不违背题面？
4. 哪个指标、可行性、稳定性或解释结果改善？
5. 是否有同协议 Baseline 与实际运行证据？

只有换模型、堆叠术语、调参或一次偶然提升时，标记 `伪创新风险`。
