# Simulation and Network Model Family

## Candidates

确定性情景、Monte Carlo、离散事件/系统仿真、图论、最短路、最大流、中心性、鲁棒网络和情景组合。

## Fit

随机输入分布、相关结构、网络节点/边/权重/容量或情景机制可追踪；随机结果能报告收敛和不确定性。

## Baseline / Primary

解析/确定性情景、直接距离或简单连通是 Baseline；经过收敛、扰动和实际约束验证的仿真/网络模型可作 Primary。

## Data / Validation

Monte Carlo 报样本量、标准误/区间和收敛；网络报图构建规则、单位、可达性、约束和删边/加噪稳定性。

## Common Misuse

把猜测分布当事实；只报随机均值；不解释图边含义；负权仍使用不适用算法；把中心性直接等同业务重要性。
