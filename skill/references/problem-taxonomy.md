# Problem Taxonomy

分类是结构化建模决策，不是关键词匹配；一个子问题可以有多个类型。

| 类型 | 先检查什么 | 常见交付物 |
|---|---|---|
| 描述统计/参数估计 | 分布、关联、未知参数和不确定性 | 统计量、区间、图表 |
| 回归/预测/时间序列 | 目标连续性、信息时点、滞后和预测跨度 | 预测、误差、回测 |
| 分类 | 标签、类别代价和不平衡 | 类别、概率、混淆矩阵 |
| 聚类 | 是否无标签、距离和簇解释 | 分组、画像、稳定性 |
| 综合评价/排序/决策 | 指标方向、权重、补偿性和方案约束 | 分数、排名、方案 |
| 单/多目标优化 | 决策变量、目标、边界、可行性和偏好 | 解、Pareto、可行性 |
| 调度/路径/网络 | 顺序、资源、节点边和成本 | 排程、路线、流 |
| 微分方程/机理 | 状态、守恒、速率、初值和可识别性 | 轨迹、参数、情景 |
| 随机过程/排队/Markov | 状态、转移、到达/服务和稳态 | 概率、稳态、等待 |
| Monte Carlo/仿真 | 输入分布、相关结构和随机情景 | 风险、区间、情景 |
| 空间/因果/混合 | 坐标邻域、干预识别或多阶段耦合 | 空间效应、因果效应、联合方案 |

最低识别表：目标、决策变量、观测变量、约束、随机性、时间/空间关系、验证方式。任何一个仍空缺时，先回到 `analyze-problem`。
