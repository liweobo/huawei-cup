## 4. 异常与质量风险

- 缺失值：四个工作表、所有列均未发现缺失单元格。
- 完全重复：材料 3 有 1 行完全重复，其他材料为 0。是否删除需结合样本来源确认，不能仅凭统计规则自动删除。
- 温度：四个材料的温度字段均未产生 IQR 异常候选。
- 频率：按 1.5×IQR 规则，材料 1 有 54 个候选点，材料 4 有 59 个候选点；材料 2、3 未产生该类候选。材料 2、3 的实际范围含 49,990 Hz 和 501,180 Hz，需核对题面允许边界及仪器记录。
- 磁芯损耗：按 1.5×IQR 规则的候选点数分别为材料 1：372、材料 2：344、材料 3：382、材料 4：327。这些只是统计候选，不等价于错误观测。
- 1024 个磁通密度列：由于不同波形、幅值和相位在同一采样位置的自然差异，逐列 IQR 会产生大量候选。不能把这些提示直接当作异常行删除；应改用峰峰值、斜率、平台比例、周期一致性等波形级规则复核。
