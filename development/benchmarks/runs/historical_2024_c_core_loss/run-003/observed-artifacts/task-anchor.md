# Task Anchor

## Goal

对 2024 年研究生数学建模 C 题“数据驱动下磁性元件的磁芯损耗建模”做首轮整体梳理：提取题面要求，建立问题依赖关系，审计四个附件的数据结构/质量，并形成可执行的后续建模路线。

## Boundaries

本轮不训练正式分类或回归模型，不生成附件二/三的最终预测，不回填附件四，不宣称任何未运行的模型指标、参数或最优条件；题面公式图片未完成 OCR 时，只记录可从正文确认的公式结构。

## Inputs

- 题面：`数据驱动下磁性元件的磁芯损耗建模.docx`
- 训练集：`附件一（训练集）.xlsx`
- 测试集：`附件二（测试集）.xlsx`、`附件三（测试集）.xlsx`
- 回填模板：`附件四（Excel表）.xlsx`
- 当前 run：`run-003`，写入根目录为当前工作目录

## Done When

- 题面五个问题的输入、输出、约束和依赖被明确记录；
- 四个附件的工作表、行列规模、字段角色、缺失/重复/异常候选和风险被审计；
- 生成一份整体梳理报告和一份可复用的审计摘要；
- 真实已运行内容与 `NOT RUN` / `[需要验证]` 内容清楚区分。

## Risks

- 题面中的公式和图以嵌入 WMF/PNG 形式存在，当前环境缺少 `pdf2image`/LibreOffice，版式渲染和公式图像 OCR 未完成；
- 审计脚本对 1,024 个采样列会产生大量高相关候选，需将其视为波形特征工程提示而非删除指令；
- 附件一的工作表名和中文字段在部分命令输出中存在编码显示问题，报告按题面语义映射字段，不修改原始文件。
