# Task Anchor

- Goal: 使用冻结的当前 huawei-cup-2026 Skill 独立完成 2022C 第三题型 blind run，形成真实模型、可行调度、验证和审查证据。
- Boundaries: skill/ 不得修改；只访问用户指定 C 题原始目录与五份文件；禁止优秀论文、答案、他人解法或代码；保护全部历史资产。停止后等待人工审查，不修 gap。
- Inputs: 用户指定题目镜像；当前 Git HEAD 与 Skill；普通算法知识及本地库。
- Done When: 完成主要子问题或明确记录 PARTIAL；独立可行性审计、版本与来源证据、22 节报告、核心回归通过、仅新增本轮 artifact 提交推送并核对远端。
- Risks: 题面公式/图片完整性、调度语义歧义、可执行性、多目标口径、解质量证据。
- Workspace: 本 run-001 为唯一新增运行写入根；运行结束后冻结。同仓库运行是可见性披露，非 platform clean-room 声明。
- Authorization: 用户明确授权本历史题及 commit/push；Skill 的 AAR 维护要求仅以报告形式执行，遵守本轮禁止修改 Skill 的更具体指令。
