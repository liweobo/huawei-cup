# Mathematical Model: 2022 C PBS Resequencing

## Sets And Indices

- `V = {1,...,N}`: vehicles entering the paint-PBS exit in source order.
- `L = {1,...,6}`: inbound lanes.
- `P = {1,...,10}`: positions in each lane; position 10 is the receiving
  end and position 1 is the delivery end.
- `R = {1,...,10}`: return-lane positions; position 1 is the entry from the
  delivery side and position 10 is the exit to the receiving machine.
- `t in {0,...,T}`: integer seconds.
- `m in {REC, DEL}`: the receiving transfer machine and delivery transfer
  machine.

## Parameters

- `tau_rec[l]`: receiving-and-return time to lane `l`, equal to
  `[18,12,6,0,12,18]` seconds.
- `tau_del[l]`: delivery time from lane `l` to final assembly, equal to
  `[18,12,6,0,12,18]` seconds.
- `tau_ret[l]`: delivery time from lane `l` to return position 1, equal to
  `[24,18,12,6,12,18]` seconds.
- `tau_return_rec[l]`: receiving-and-return time from return position 10 to
  lane `l`, equal to `[24,18,12,6,12,18]` seconds.
- `tau_move = 9` seconds for one position movement in a lane.
- `q_i`: source order index of vehicle `i`.
- `h_i in {0,1}`: hybrid indicator.
- `d_i in {0,1}`: four-wheel-drive indicator.
- `C = |V|`.

## Decision Variables

- `x_{i,l,p,t} in {0,1}`: vehicle `i` occupies inbound lane `l`, position
  `p`, at second `t`.
- `r_{i,p,t} in {0,1}`: vehicle `i` occupies return position `p` at second
  `t`.
- `z_{i,t} in {0,1}`: vehicle `i` is on a transfer machine at second `t`.
- `y_{i,t} in {0,1}`: vehicle `i` reaches the PBS-final-assembly receiving
  point at second `t`.
- `a_{i,l,t} in {0,1}`: the receiving machine starts a receive action
  delivering `i` to lane `l` at `t`.
- `b_{i,l,t} in {0,1}`: the delivery machine starts an assembly action from
  lane `l` for `i` at `t`.
- `c_{i,l,t} in {0,1}`: the delivery machine starts a return-lane action
  from lane `l` for `i` at `t`.
- `u_{i,l,t} in {0,1}`: the receiving machine starts moving `i` from return
  position 10 to lane `l` at `t`.
- `o_t`: final-assembly arrival order induced by the `b` actions.

All variables are binary except `o_t`, which is an integer vehicle index in
the executable sequence representation.

## Objective

The four stated scores are computed directly from the final sequence and
completion time:

```text
S1 = 100 - sum over consecutive hybrid pairs [gap != 2]
S2 = 100 - number of drive blocks with unequal 4WD/2WD counts
S3 = 100 - number of inbound-to-return actions
S4 = 100 - 0.01 * max(0, T - (9C + 72))
Z  = 0.4*S1 + 0.3*S2 + 0.2*S3 + 0.1*S4
```

The weights and score rules are fixed by the statement; no arbitrary weight
or trade-off parameter is introduced.

## Hard Constraints

### Capacity And Uniqueness

For every `t`:

```text
sum_i x_{i,l,p,t} <= 1                         for every l,p
sum_i r_{i,p,t} <= 1                           for every return position p
sum_l,p x_{i,l,p,t} + sum_p r_{i,p,t} + z_{i,t} + y_{i,t} <= 1
```

Each vehicle is assigned to at most one PBS region at a time, each lane
position holds at most one vehicle, and each return position holds at most
one vehicle.

### Transfer-Machine Capacity And Non-Interruption

```text
sum_i,l a_{i,l,t'} + sum_i,l u_{i,l,t'} <= 1
sum_i,l b_{i,l,t'} + sum_i,l c_{i,l,t'} <= 1
```

for every active interval `t'` covered by an action. An action that starts
at `t` occupies the corresponding machine for its stated duration and cannot
be interrupted; the next action cannot start before the previous action plus
the listed return-to-home time has completed.

### Lane Direction And Immediate Movement

For each lane and each interior position:

```text
occupancy at position p can only move to p-1
if p-1 is empty, movement from p must start immediately
```

The return lane moves from position 1 toward position 10 under the same
capacity rule.

### Delivery Rule

The delivery machine can remove only from inbound position 1 or return
position 10. If any inbound position 1 is occupied and the delivery machine
is available, the model must start a delivery action. The return-lane
vehicle cannot be sent directly to final assembly.

### Source-Order And Resequencing

The paint-PBS exit is consumed in source order, but a vehicle can be placed
in the return lane and then reintroduced into an inbound lane. Thus the final
assembly order is a feasible permutation of `V`, not an arbitrary
permutation: it must be generated by the action variables while respecting
all lane and machine constraints.

## Baseline

`source-order` is the simplest legal baseline:

- receive each source vehicle into the least-loaded available lane;
- follow the required FIFO movement;
- deliver from position 1 without using the return lane.

It is feasible under the statement rules and provides a common comparison
for every subproblem.

## Exact And Heuristic Scope

The full model is a discrete-time, multi-machine scheduling problem with
vehicle identity, lane positions, return-lane loops, sequence-dependent
objectives and finite buffers. An exact global MILP is not claimed: the
full 318-vehicle instance is not solved to proven optimality in this run.
The implemented method is a deterministic discrete-event heuristic with
source-order and score-aware greedy policies. All reported values are
therefore **BEST FOUND / HEURISTIC**, not global optima.
