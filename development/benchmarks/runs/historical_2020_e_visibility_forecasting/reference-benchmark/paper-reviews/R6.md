## Q3 scale and paper/code discrepancy

Pages 35–44 give dark-channel, guided-filter and camera-calibration theory. Page 41 admits that target distance is not supplied and says calibration should estimate it, but no scene correspondences, solved camera parameters or calibration residuals are reported. Appendix pp67–68 instead computes extinction with a hard-coded distance of **30** for every pixel: `belta=abs(total/(720*1280*30))`. The main text's calibration chain therefore does not match the printed implementation.

The code also computes transmission directly from the dark channel without the stated atmospheric-light normalization and contains `Jdack` where the maximum-removal loop references `Jdark`. These are static discrepancies; no appendix code was executed. The reported 89.28–94.51m series depends linearly on an unproven 30m scale. Output: ABSOLUTE_MOR_METRES; identifiability: UNSUPPORTED.
