## Q3 scale and implementation

Pages 28–36 discuss rejected brightness and Monodepth2/perspective approaches. The final model derives beta from the mean log-transmission difference between two road regions divided by D2−D1, then uses MOR = −ln(0.05)/beta. Page 33 acknowledges the actual camera distance was not supplied.

The 6m stripe, 9m gap and approximately 20cm width on pp30/34 are generic external road-marking information, not verified measurements of this scene. Page 35 assumes the optical distance difference equals the 9m road gap. Provenance: EXTERNAL_SOURCE for the cited generic dimensions, AUTHOR_ASSUMPTION for their scene application; benchmark access class REFERENCE_ONLY_INPUT for both. Uniform beta, negligible absorption and dark-channel parameters remain model assumptions. There is no direct measured C0; the dark-channel prior and literature weight 0.95 provide assumptions instead.

The claimed 105–140m series is an ABSOLUTE_MOR_METRES claim, with PARTIALLY_SUPPORTED identifiability: an explicit conditional physical mapping exists, but scene calibration and independent MOR validation do not close the chain.

Static appendix review, visually checked pp56–57, exposes two inconsistencies: the first ROI slice is 7×3 although division by 49 is used, and the second-region assignment uses `POI2 = POI1 / (A * 255)`, overwriting its own region information. These conflict with the stated two independent 7×7 regions. No appendix code was executed, and no new MOR values were computed.
