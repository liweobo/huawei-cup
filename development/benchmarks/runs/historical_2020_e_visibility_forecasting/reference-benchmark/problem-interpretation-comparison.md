# Problem interpretation comparison

| Chain stage | Frozen Skill solution | Reference pattern | Assessment |
|---|---|---|---|
| Source/input | Uses only recovered AMOS and highway BMPs; airport video absent | All six use airport video and paper-specific pairings/calibration | These inputs are REFERENCE_ONLY_INPUT and cannot repair the blind run |
| Q1 target | Same-time meteorology → MOR estimation | All six fit same-time RVR/MOR relations | Agreement supports the frozen estimation/forecast separation |
| Q2 target | Same-time airport image → AMOS visibility; source-blocked | All six use the missing video; targets vary among MOR, RVR, mixtures or unspecified bands | References show material access, not current source recovery |
| Q3 output | Relative contrast proxy only | All six publish metres using road/camera/contrast assumptions | Every metric chain depends on reference-only or author-assumed scale; no independent highway MOR validation |
| Q4 target | Future highway proxy at explicit origin; no absolute 150m claim | All six extrapolate Q3-derived 100-point series | Full history can be valid at the last frame; forecast performance still needs backtesting |
| Forecast origin | Explicit last available frame | R5 explicit; R1/R6 recoverable with indexing issues; R2–R4 informal/inferred | Frozen origin discipline is stronger |
| Feature availability | Past targets/current features only; no realized future weather | References' Q4 models generally use only derived history | No demonstrated future-weather leakage; no new availability gap |
| Validation | Rolling/common origins, persistence, per-horizon metrics | No paper tests the final long extrapolation at multiple historical origins | Reference claims are weaker evidence for future correctness |
| Uncertainty | Sequential prediction bands with empirical coverage | No calibrated future interval in any paper | Frozen solution is stronger |
| Final claim | Improving proxy only; absolute MOR/time withheld | Five claim 150m time; R6 claims 200m clearing time | Numeric claim does not close calibration + forecast-validation chain |

The papers and frozen run largely agree on the four problem roles. The decisive differences are source access, willingness to assume a physical scale, and forecast validation standards. These are G2/G3/G4/G5 distinctions; they do not show a missing general forecasting contract that caused the frozen run to fail.
