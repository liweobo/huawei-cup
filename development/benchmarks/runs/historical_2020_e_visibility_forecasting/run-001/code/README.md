# Reproduction

Run `run_analysis.py` from a Python environment containing NumPy, pandas, Pillow, SciPy, and scikit-learn. It reads only retained originals under `source-provenance/original/` and rewrites the retained output/experiment-record artifacts. `test_analysis.py` contains deterministic semantic/leakage and metric tests.

No trained model dump, extracted archive, rendered page, video cache, or excellent-solution material is required.
