# Results

The canonical numeric outputs remain under `outputs/` because they are directly produced by the experiment script. This directory holds report-facing figures and this index only; every figure is generated from the CSV output rather than hand-drawn.

- `figures/q2-gamma-vs-time.png`: requirement comparison over the four-second motion.
- `figures/q2-order-convergence.png`: maximum reflection-order refinement at t=2 s.
- `figures/q2-requirement-margin.png`: min/max gamma for the two supplied material cases.
