## Problem setting

The task is ASIC carrier-recovery DSP design for a 16QAM optical communication model. The receiver is described as: dispersion compensation, carrier recovery (CR) for phase noise, symbol decision, and inverse mapping. The stated performance quantity is RSNR cost, defined relative to the SNR at which a BER threshold is reached in an AWGN-only reference.

## Given definitions and formulas

The following are transcribed from the DOCX. Where the rendered equation has a complex-power or unit ambiguity, the ambiguity is retained here rather than silently corrected.

1. `n_k = r_k - s_k`.
2. The DOCX writes `P_n = (1/N) sum n_k^2`; the prose calls this noise average power. For complex samples, the implementation uses `|n_k|^2` and labels that as an engineering interpretation.
3. The DOCX writes `P_s = (1/N) sum s_k^2`; the implementation uses `|s_k|^2` for complex symbols and labels that as an engineering interpretation.
4. `SNR = P_s / P_n`.
5. `SNR_dB = 10 log10(P_s / P_n)`.
6. `S_1(t) = S_0(t) exp{j theta(t)}`.
7. `d theta = theta_(k+1) - theta_k = 2 pi * (LW / f_b) * X_k`, where the OMML formula contains the fraction `2 pi LW / f_b`, `LW` is stated in kHz, `f_b` is baud rate, and `X_k` has mean zero and variance one.
8. The OMML structure is `H(f) = exp[j * (lambda^2 pi D_z / c) * f^2]`; the surrounding linear text is visually ambiguous. The implementation uses this OMML-parsed form, with `lambda=1550 nm`, `D_z` as cumulative dispersion in ps/nm, `c` as light speed, and `f` in Hz.

## Subproblems

### Problem 1

Given 150 Gbaud standard 16QAM, `LW=100 kHz`, `D_z=20,000 ps/nm`, parallelism 128, and no fixed-point quantization, design a CR algorithm using adders, multipliers, LUTs, and buffers with minimum pilot overhead subject to RSNR cost `<0.3 dB`.

### Problem 2

For `LW` from 10 kHz to 10 MHz and `D_z` from 0 to 10,000 ps/nm, quantify the relation among dispersion, linewidth, pilot overhead under RSNR cost `<0.3 dB`.

### Problem 3

Extend Problem 2 by including ASIC resource and fixed-point quantization. Pilot overhead is free to vary, but payload throughput must exceed 145 Gbaud. Find a minimum-resource CR design.

### Problem 4

Choose a representative Problem 3 scenario and construct a joint performance-resource cost function. Give an automatic bit-width and implementability search with quantitative results.

## Explicit constraints and omissions

- The question gives parallelism 128 for Problem 1. This run keeps 128 lanes for the ASIC resource model in Problems 3-4 and records that as a modeling assumption.
- The question says dispersion compensation and BER-computation complexity/resources are excluded; only phase estimation and phase compensation resources are counted.
- A BER threshold value is not stated in the extracted DOCX. Main results use `BER*=1e-2`; `BER*=1e-3` is a sensitivity run. This is `PARAMETERIZED`, not a claim about the original threshold.
- No numerical signal file is attached. Quantitative results therefore come from reproducible synthetic communication frames generated by the code in this run.
- Pilot placement, pilot constellation point, phase-noise/dispersion ordering, fixed-point scaling, and resource weights are design assumptions and are listed in `design-model.md`.
