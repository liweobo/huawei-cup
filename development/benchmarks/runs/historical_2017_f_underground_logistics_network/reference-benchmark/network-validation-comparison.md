## Strengths Retained

Run-002 preserves source provenance, directed and diagonal freight, layer
semantics, candidate versus built links, coverage, demand/flow conservation,
hard-capacity gating, physical-edge costing once, independently reconstructed
objective, scoped solver claims and explicit failure scenarios. It distinguishes
static from timed feasibility and refuses fake daily-clearing or30year claims.
These strengths coexist with poor design quality and unresolved operations.

No row is labeled `MISSING_CAPABILITY` merely because references use an algorithm
not tried by run-002. Potential contracts are assessed against current Skill
text and actual blind-run impact in `generalizable-gaps.md`.

## Attribution Limitation

This historical run was conducted with a detailed user audit prompt. Passing
individual audits is evidence of the **observed Skill-assisted workflow**, not
a controlled ablation showing that the short network reference alone would
elicit every check unaided. This benchmark neither proves universal
NETWORK_MODELING_READY nor establishes a missing rule from a weak solver result.
Current contracts must be read compositionally, and residual uncertainty retained.
